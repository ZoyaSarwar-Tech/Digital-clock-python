# 🕒 Advanced Digital Clock

A modern and beginner-friendly Digital Clock application built using **Python** and **Tkinter**. The application displays the current time, date, and day in real-time and automatically updates every second.

## 📸 Preview

```text
DIGITAL CLOCK

08:45:20 PM

Sunday

31 May 2026

[ Exit ]
```
## ✨ Features

- Real-time digital clock
- Displays current day
- Displays current date
- Automatic update every second
- Simple and clean graphical interface
- Exit button to close the application
- Responsive window with minimum size restrictions
- Beginner-friendly code structure

## 🛠 Technologies Used

## 📖 How It Works

1. Creates a Tkinter window.
2. Displays labels for time, date, and day.
3. Fetches current system time using `strftime()`.
4. Updates labels every second using `after()`.
5. Runs continuously until the user closes the application.
